# SWDFA501 Front-End App Development with React.JS — WORK 1

Complete solutions for both practical tasks in the supplied assignment.

## Task 1 — ReactJS E-commerce Project
- React + Vite
- React Router v6
- Navbar + Footer
- Home, Products, Cart, Profile, 404
- `/home` redirect to `/`
- URL filters using `useSearchParams`
- Product details `/products/:id`
- Nested Reviews and Specs routes using `<Outlet />`
- Client-side navigation with `NavLink`/`Link`

## Task 2 — ReactJS Hospital Management System
- React + Vite
- React Router v6
- Dashboard, Patients, Appointments, Billing, Pharmacy, 404
- `/home` redirect to `/`
- Patient and pharmacy filtering using `useSearchParams`
- Patient detail `/patients/:id`
- Nested History and Billing routes using `<Outlet />`
- Active navigation highlighting
- Back to Patients using `useNavigate()`

## Run either project
```bash
cd Task1_Ecommerce
npm install
npm run dev
```
Or:
```bash
cd Task2_Hospital
npm install
npm run dev
```

The projects are independent and ready for GitHub/Vercel deployment.
